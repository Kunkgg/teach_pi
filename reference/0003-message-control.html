Pi 运行中消息控制卡

先判断消息是在改变当前任务，还是新增下一项任务。

意图默认操作效果
改变当前任务的方向、范围或约束输入消息，按 Enter作为 steering，在当前 turn 的工具调用结束后送达
当前任务完成后再做一件事输入消息，按 Alt+Enter作为 follow-up，在全部当前工作结束后送达
修改尚未送达的队列消息Alt+Up取回编辑器
当前执行已无价值或可能有害Escape中止运行，并把队列消息恢复到编辑器
记忆句：改现在 = Enter；加以后 = Alt+Enter；改队列 = Alt+Up；立刻停 = Escape。

安全边界

  • Abort 不会回滚已经发生的文件修改、命令或网络副作用。
  • 默认 steering 与 follow-up 都逐条送达；除非出现真实需求，不必改成一次送达全部。
  • 队列只用于短期交互。独立且长期的任务应使用新 session、fork 或项目任务文件。
