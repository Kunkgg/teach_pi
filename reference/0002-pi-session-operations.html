Pi 会话操作地图

历史是一棵完整的树；模型每次只看到其中一条经过压缩处理的活动路径。

意图操作结果
回到同一会话的旧节点，探索另一方案/tree 或 Esc Esc同一 JSONL 文件中新增分支
从旧的用户消息开始独立任务/fork创建新的 session 文件
复制当前活动路径再继续/clone创建新的 session 文件
释放上下文窗口/compact旧上下文被有损摘要；原始历史仍保留
恢复其他会话/resume 或 pi -r切换 session 文件
为会话建立可检索名称/name <name>保存显示名称
查看文件、ID、token 与成本/session显示当前会话元数据
三个不要混淆的对象：
Session file = 完整树；active branch = 当前根到叶路径；model context = 活动路径经 compaction 后实际发给模型的内容。

默认决策

  • 只是比较方案：用 /tree，让替代路线留在一起。
  • 任务将长期独立演化：用 /fork 或 /clone。
  • 上下文快满：先确认关键决定已写入项目文件，再依赖自动压缩或运行 /compact。
